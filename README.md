# JFShare

Just File Share - share files with no size limit, unlimited bandwidth, no sign-in required, peer-to-peer


## Official instance:

available under these 2 links:

### https://matszwe02.github.io/JFShare

### https://jfshare.vercel.app


## Share files with ease

- No backend needed (but preferred for ease-of-use)
- Fully working through WebRTC
- No filesize limit - you can send terabyte files
- No registration or anything, just open the website and start sharing
- Bi-directional - when you open a connection, you can send as many files between PCs
- Directory transfer support (for supported browsers)

## But where's the catch?

You are the server - files are available as long as you maintain the connection. You can not upload the files to be downloaded later. Server only pairs devices.
